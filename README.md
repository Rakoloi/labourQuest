# labourQuest (TshwaraSpane)
TshwaraSpane is a full-stack local job marketplace platform designed to connect people looking for short-term work opportunities with individuals or businesses needing assistance with tasks and services. The platform allows users to seamlessly switch between being a job seeker and a job creator within a single application, creating a more flexible and accessible local job ecosystem.


# Features

## Mobile Application
Built using React Native and Firebase.

### Core Functionality
- Create and manage job listings
- Browse and accept available jobs
- Track job progress through:
  - Pending
  - Active
  - Completed
- View centralized job history
- Real-time data updates using Firebase Firestore
- Firebase Authentication using email and password
- Location-based job information
- Responsive and user-friendly mobile experience

---

## Dashboard
Built using Next.js and Firebase.

### Dashboard Capabilities
- Monitor platform activity
- Manage job workflows
- View and manage job listings
- Track accepted and completed jobs
- Administrative management features
- Modern responsive web interface
